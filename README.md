# User Management API

A simple backend REST API built with **Node.js**, **Express.js**, and **MongoDB** that performs CRUD operations with JWT-based authentication.

## Features
- User registration and login
- JWT access & refresh token authentication
- Protected user profile route
- CRUD operations on users
- Tested using Postman

## Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT & bcrypt
- Postman

## Usage
- Run the server
- Test APIs using Postman
- Use `Authorization: Bearer <token>` for protected routes
